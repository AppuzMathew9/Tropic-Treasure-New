# Tropic Treasure website source

Editable static website. No build step or paid editor required.

- index.html: content and page structure
- styles.css: colours, typography and responsive layout
- script.js: product dialogs, menu and enquiry brief download
- assets/: photographs copied from the supplied reference website

## Edit and preview
Open this folder in a code editor. Open index.html in a browser, or run:

    python -m http.server 8000

Then visit http://localhost:8000.
